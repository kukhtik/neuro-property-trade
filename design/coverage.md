# NPT UI v3 — карта покрытия и интеграция (coverage)

> К `design/ui-prototype.html` (31 состояние × стили neuro/evil), спека:
> `docs/specs/ui-full-redesign-spec.md` §7.1.4. Полнота проверяется машинно:

## 1. Функциональная карта F-01…F-73

Формат: **F-№** → сцена/элемент прототипа (стиль и язык не влияют — состояния одни).

### 4.1 Доска
- **F-01** кольцо целиком — все сцены; board 722px@1440, 422px@880 — без обрезки и камеры по умолчанию.
- **F-02** анатомия клетки (имя, полоса группы, цена, дома/отель, залог, бейдж владельца) — `#board .tile` во всех сценах.
- **F-03** спецклетки (СТАРТ/тюрьма/стоянка/иди-в-тюрьму/налоги/жд/коммуналка/шанс/общество) — иконки игры по типам.
- **F-04** подсветки: active / selected / valid-target — сцены `purchase` (цель), `turn-human` (активная), инспектор (selected).
- **F-05** кино-камера — опция `settings.spectacle` (вкладка «Интерфейс»), по умолчанию выкл; правило: кольцо не режется никогда.

### 4.2 Фишки и места
- **F-06** единый цвет (клетка=фишка=строка=журнал) — `colorVar(place)` всюду; сверяет `check_package` (пиксели и токены).
- **F-07** веер фишек на одной клетке — `renderTokens()` (+сцена `move`).
- **F-08** чей ход / тюрьма ×попытки / away / банкрот — карточки мест (`jail`, `turn-human`).
- **F-09** движение по кольцу — сцена `move`; выключенные анимации — мгновенно (атрибут `data-anim=off`).
- **F-10** состав строки места (фишка, имя, деньги, позиция НАЗВАНИЕМ, тайлы, дома, залоги, карта) — `.pcard`.
- **F-11** полный свод по наведению — `plr.tooltip` на карточке.
- **F-12** клик по строке — слежение/подсветка клетки (`bindSeatClick`).
- **F-13** статистика стола (дома/отели/залоги) — блок `.stats`.
- **F-14** полоса владения — `.ownbar` (+пропозал `plr.owned`).
- **F-15** холодное состояние мест — `cold` (пустое состояние с CTA).

### 4.3 Центр доски
- **F-16** кубики: сумма, дубль (`die.doubles`), третий дубль → тюрьма; без анимаций — мгновенно — `move`/`ai`/`jail`.
- **F-17** карточка решения (покупка/аукцион) в центре — `purchase`/`auction`.
- **F-18** баннеры: покупка, старт аукциона, тюрьма, победа (`reject`/`win`/`auction`).
- **F-19** раунд и банк парковки — чипы шапки (pot — при включённом free parking).

### 4.4 Шапка
- **F-20** «чей ход» — чип хода с мини-фишкой и цветом.
- **F-21** фаза человеческим языком — `phase.*` (в т.ч. «до старта»).
- **F-22** шаги хода — 4 точки с тултипами `ph.0..3`.
- **F-23** таймер/ожидание — зона решения: кольцо при лимите; `нейро` — «ожидание Neuro…» (P-12).
- **F-24** бейдж роли — `mode.player`/`mode.admin` (в `admin`).
- **F-25** точки входа — иконки: настройки, правила, рестарт, язык, скин, звук, наблюдатель, админ (F12).

### 4.5 Консоль действий
- **F-26** набор действий движка (бросок/купить/отказ/ставка/оплата/карта/строить/продать/заложить/выкупить/торг/ответ/конец) — по сценам; недоступное видно неактивным с причиной (инспектор `build`).
- **F-27** контекстная фраза — строка промпта (`act.hint_*`).
- **F-28** статусы (ваш ход / ИИ / наблюдение / холод) — `turn-human`, `ai`, `observer`, `cold`.
- **F-29** горячие клавиши B/N — бейджи на кнопках + работающие клавиши в прототипе.
- **F-30** последний бросок остаётся — чип в консоли + центр после анимации.

### 4.6 Журнал
- **F-31** лента: время, имя цветом, текст с НАЗВАНИЯМИ клеток, тег типа.
- **F-32** фильтры: игрок, 8 типов (`ty.*`), «Деньги».
- **F-33** счётчик «показано/всего» + автоскролл.
- **F-34** экспорт `.jsonl` — кнопка ⭳ и тосты успеха/ошибки (`gv.journal_export_*`).
- **F-35** наблюдатель — журнал 400px + широкая лента (`observer`).
- **F-36** пустой журнал — дружелюбное состояние (`cold`/`empty`).

### 4.7 Справка по клетке
- **F-37** имя/тип/группа/цена/аренда/владелец/дома/залог — `.ins-b`.
- **F-38** открытие кликом/hover, pin, ✕, авто-скрытие, пустое «Кликните по тайлу доски».
- **F-39** выбор клетки для менеджмента — `selTile` → модалка `build` и кнопки инспектора.

### 4.8 Модалки решений
- **F-40** стройка/залог (`build`), **F-41** торг-составление (`trade`), **F-42** входящая (`trade-in`),
- **F-43** аукцион свой/наблюдение (`auction`, `auction-watch`; кнопки только у биддера — решает движок),
- **F-44** отказ движка с причиной (`reject`), **F-45** один экземпляр + scrim/ESC (`modal host`).

### 4.9 Настройки матча
- **F-46** вкладка «Игроки» (драйверы, имя, фишка, цвет, персонаж, добавить/удалить, роль хоста, порядок, валидация),
- **F-47** «Создать партию для друзей» (кнопка → оверлей `invite`), **F-48** «Правила» с тегами живьём/рестарт,
- **F-49** «Темп», **F-50** «Интерфейс» (анимации/журнал/камера/звук/язык/скин — живьём),
- **F-51** «Данные» (сид, 16–64, пресеты), **F-52** тултип у каждого поля, **F-53** кнопки Старт/Применить/Правила/Сброс/Закрыть,
- **F-54** оверлей правил собирается из текущих настроек.

### 4.10–4.16
- **F-55** итоги: победитель, статистика, РЕВАНШ/НАСТРОЙКИ (`win`).
- **F-56** наблюдатель: статус без кнопок; **F-57** доска целиком, журнал шире, места сворачиваются; **F-58** честная подпись «паузы нет»; **F-59** фоллоу кликом.
- **F-60** приглашение хоста (ссылки+копирование), **F-61** лобби (подключение/ошибка+повтор/обычный запуск).
- **F-62**…**F-66** админ: Быстрые (форс-ролл/пас/откат/сброс away), **F-63** Состояние (сводка, JSON-дамп, снапшоты → подтверждение), **F-64** События (фильтр + экспорт `.jsonl`), **F-65** Правки (13 операций, поиск, каждое показывает только свои поля, инлайн-результат), **F-66** журнал админа + подтверждения деструктивных — сцены `admin-quick`, `admin-state`, `admin-edits`.
- **F-67** тосты 13 видов + анти-спам (`rent_merged`), **F-68** не поверх консоли/клеток, **F-69** в наблюдении остаются.
- **F-70** звук (кнопка+настройка), **F-71** анимации выкл (мгновенные состояния).
- **F-72** скины: переключатель neuro/evil/default (+classic в файлах), полная переодетость; **F-73** RU/EN живьём.
- **4.17** dev-инструменты — вне дизайна (не рисуются).

## 2. Проблемы P-1…P-16 → как решены

- **P-1** камера резала кольцо → доска всегда целиком (клетка = min(ширина,высота)/11); «кино» — опция в настройках, по умолчанию выкл (F-05).
- **P-2** четыре массива цветов → один источник: `player` скина; клетка/фишка/строка/журнал берут `--p<N>`; сверяет `check_package.py`.
- **P-3** всеобщий перенос/растяжение → две роли (`t-value`/`t-para`) и фабрики `UiTheme.label/label_wrap`; аудит живьём, третьей роли нет.
- **P-4** растяжение-флаг → ровно один `data-grow` на строку, помечен в макете; аудит считает нарушения (0 в каждом состоянии).
- **P-5** уведомления поверх управления → хост тостов в правом доке; в компакте — строкой в консоли (не поверх); гейт: пересечение с `stage/act` = 0.
- **P-6** жёсткий 885px шапки → компакт-профиль: wordmark/шаги скрыты, чипы = числа, все 8 контролов на 880px; ничего за кадром.
- **P-7** микро-ссылки → вторичные действия — настоящие кнопки 30px с тултипами, всегда видимы.
- **P-8** текст на клетках → разведены блоки (иконка/имя/цена), перенос по словам, кламп 2 строки; эллипсис только в компакт-имени.
- **P-9** каскад модалок → один экземпляр, scrim/ESC/кнопка; повторное открытие перезаписывает.
- **P-10** мёртвый журнал с тегами → лента с первой секунды, имена клеток словами, тег — переведённая категория, один язык.
- **P-11** язык не перерисовывал композит → смена языка **пере-выводит** все составные строки и модалки из состояния (`relabel`+полный ре-рендер).
- **P-12** ложный таймер → нет лимита — нет кольца; SDK-место — «ожидание Neuro…», не отсчёт.
- **P-13** пустой центр → сцена: кубики, карточка решения, баннеры, водяной знак.
- **P-14** фолбэки скинов → все скины полны; default получает `group`/`ring_bg`; `tokens.json` фиксирует полноту; сверяет `check_package`.
- **P-15** anchors/size overridden → контейнеры расставляют детей (grid/flex), абсолют — только фишки/баннеры внутри доски; предупреждений в макете нет.
- **P-16** узкие окна схлопывались → 880×600 — рабочий режим: кольцо 422px, рейлы, консоль 96px, дроверы; проверено рендером `compact`.

## 3. Что изменилось против текущего интерфейса

| Было (замороженный макет) | Стало (v3) | Почему |
|---|---|---|
| шапка с role-табами и жёсткими 885px | шапка-чипы: ход/шаг/раунд/банк + зона решения, компакт-политика | P-6, I-3, F-23 |

| тосты сверху-центр поверх поля | хост тостов в правом доке; компакт — тикер в консоли | P-5, F-68 |

| пустой центр | сцена с кубиками/карточкой/баннерами | P-13, F-16..F-18 |
| таймер «всегда» | кольцо только при лимите; SDK — «ожидание» | P-12 |
| перенос/растяжение у всех меток | две роли, один grow, аудит | P-3, P-4 |
| скины с фолбэками | полные скины + 7 новых токенов | P-14, I-6 |

## 4. Предложенные строки (12 новых ключей)

`design/src/strings_proposed.json` → в `game/i18n/data_*.gd`:
`plr.owned`, `plr.owned_tip`, `plr.jail_tip`, `act.timer_tip`, `act.observer_note`,

`ins.price`, `ins.rent`, `die.doubles` — все используются прототипом и резолвятся в обоих языках.
Композиция допускает тримминг ведущего разделителя « · » у суффикс-фрагментов
(`act.observer_sdk`) — правило для адаптера, см. открытые вопросы.

## 5. Открытые вопросы (решение владельца)

1. **Group-палитра `default`.** Скин `default` не несёт `group.*`; пакет подставляет набор
   `classic`. Вопрос: закрепить за `default` отдельную палитру групп или принять classic-набор?
2. **Цвета мест 7–8.** В скинах 6 цветов, мест до 8. Предложены `#ffd166`/`#8f9bff` (neuro/evil)
   и `#46c8b8`/`#d46a9e` (default/classic) — принять или заменить.
3. **12 новых ключей** (§4) — включить в i18n-файлы (сейчас живут только в пакете).
4. **Скин `classic` в переключателе.** F-72 требует ≥3 (neuro/evil/default); `classic` и
   служебный `_stress` — поставочные файлы. Оставить в переключателе только три?
5. **Порог компакт-клетки 44px.** Сохранён; если стрим просит крупнее — поднять до 48px
   (это одна цифра в `tokens.json.metrics`).
6. **Фрагменты строк.** `ins.price`/`ins.rent` — куски `ins.body`; решить, дробить ли
   `ins.body` на переиспользуемые фрагменты или собирать из отдельных ключей.
7. **Правило разделителя.** Зафиксировать в адаптере тримминг ведущего « · » (иначе возможны
   двойные разделители в статусах).

## 6. Ворота реализации (что добавят к текущим гейтам)

Оракул 407 тестов и 17 проб сейчас зелёные (проверено на этой ветке). К внедрению предлагаются
новые поведенческие пробы:

| Проба | Проверяет |
|---|---|
| `ui_regions_probe` | имена узлов = id реестра; все регионы существуют на всех профилях |
| `text_roles_probe` | ни одного текста без роли; ≤1 grow на строку (повтор аудита макета в игре) |
| `toast_guard_probe` | тосты не пересекают `stage`/`act` на wide/desktop/compact (F-68) |
| `min_size_probe` | 880×600: каждый контрол внутри кадра (P-6, I-10) |
| `settings_tags_probe` | каждое поле настроек с тегом живьём/рестарт + тултипом (F-52) |
| `journal_names_probe` | расширение `journal_text_probe`: в ленте нет «клетка N»/«tile N» |
| `i18n_additions_probe` | 12 новых ключей в RU и EN |
| `mockup_parity` | `compare_mockup.py`, перенастроенный на `design/ui-prototype.html` и реестр |

**OpenDesign lint:** `od lint design/ui-prototype.html --fail-on p0` — exit 0 (0 P0, 0 P2).
Единственная P1 «raw-hex» (163 значения) — сознательная: спека §7.3 сама требует hex-палитры
в `:root[data-theme="…"]`-блоках для машинной сверки, вторая половина — пиксели арта игры
(встроенный спрайт из `game/assets`). Гейт поставлен на P0.

## 7. Воспроизведение пакета

```sh
python design/tools/build_data.py          # доска/i18n/скины из игры → i18n.json, src/data.js
python design/tools/build_prototype.py     # палитры из skin.json + спрайт из game/assets → ui-prototype.html
python design/tools/check_package.py       # палитра=i18n=регионы=доска: согласие с игрой
py -3.12 design/tools/render_prototype.py --all --themes neuro,evil   # 62 рендера + смоук-гейт
```
