# Задание: развить Б1 «кольцо во весь кадр» — Показывать, а не писать + Живые анимации

Концепт Б1 принят заказчиком как основа. Его файл — `files/boardfirst-1-fullring.html`.
Развить надо ДВЕ вещи. Всё остальное (требования `brief.md` R-1…R-18, палитра `skin-neuro.json`,
строки `scene-data.md` дословно, пять фактов хода, R-12 «ни одна функция не исчезает») — без изменений.

## 1. Показывать, а не писать

Мысль заказчика: **зачем писать, если можно показать**. Сейчас многое сказано словом там, где
состояние можно показать формой, светом, движением или цифрой. Ищи такие места и заменяй показом.

Что считается «показать» (в порядке силы):
1. **движением** — фишка едет, дом вырастает, свет гаснет, полоса бежит;
2. **формой** — высота, толщина, заливка, заштрихованность, положение;
3. **числом** — «3» вместо «три дома», «×2» вместо «двойная аренда», счётчик вместо перечисления;
4. **знаком** — только из объявленного набора (см. ниже), и только если знак понятен сам.

Что остаётся словом всегда: имена мест, названия клеток, деньги, строки журнала, подписи кнопок
(кнопка — слово, не значок).

**Про знаки.** Спецификация (`brief.md` §R-9/R-10) запрещает значки и односимвольные подписи.
Заказчик разрешил ПОПРОБОВАТЬ символику. Поэтому: если хочешь ввести знаки, объяви их В ПЕРВОЙ
строке файла комментарием вида

и для каждого дай словесную легенду, видимую в кадре (не только в `.md`). Знак без легенды в кадре
— не принят. Эмодзи запрещены полностью. Не вводи знаки ради красоты: каждый обязан заменять
слова, которые иначе заняли бы место, и обязан быть понятен без пояснения (проверь себя: поймёт ли
человек, увидев впервые?).

## 2. Живые анимации

Сейчас макеты статичны: события нарисованы кадрами, но не играют. Нужна ЖИЗНЬ из самого файла:

- Анимации — **на чистом CSS** (`@keyframes`, `transition`), без `<script>`. Страница открывается и
  сразу живёт: что-то движется в кадре без единого нажатия.
- **Все 11 событий** обязаны реально играть, а не быть нарисованными: ход, бросок, покупка, аренда,
  аукцион, сделка, стройка, залог, банкротство, конец игры, пауза. Разумный приём — одна общая
  временная шкала (`animation-delay` как расписание), где события идут друг за другом по кругу.
- **Длительности — из `tokens.json`** (`fast/base/slow`, `card`, `dice_roll`) или из `motion` скина.
  Ни одной выдуманной цифры: в `.md` — таблица «событие → что двигается → длительность».
- **Выключатель анимаций.** Кадр обязан уметь застыть: без анимаций состояние всё равно меняется,
  но мгновенно (как переключатель «Анимации» в продукте). Сделай это доступно без `<script>` —
  например `@media (prefers-reduced-motion: reduce)` и/или элемент-переключатель на CSS.
- **Живость должна быть смысловой.** Не «всё мигает»: движение означает событие, а не украшает.
  Волна по кольцу — ход перешёл; дом вырастает — построили; свет гаснет — залог; гаснет вся клетка —
  банкротство.
