# Второй набор концептов: «доска главная» (правка задания 19.10)

Заказчик посмотрел первый набор и сказал: концепты слишком держатся за всё остальное вокруг.
**Разрешение явное:** можно менять размеры других окон и панелей. Пример заказчика: уменьшить
центральные поля (панно внутри кольца) и соответственно уменьшить там шрифт, чтобы отдать площадь
**клеткам доски**.

## Что изменилось по сравнению с первым набором

| | первый набор | этот набор |
|---|---|---|
| площадь кольца | как в продукте | **доска — главная**: кольцо занимает максимум кадра, клетки крупные |
| центральное панно | сохранялось почти как есть | **можно и нужно урезать** (узкий хаб); кегли в нём можно уменьшать |
| прочие панели | сохранялись | можно менять размеры, сжимать, переносить |
| glance-слой (чей ход, фаза, раунд, банк) | жил в панно | **ищите ему лучшее место**: углы кольца, полоса-тикер по низу, боковая колонка-табло — где угодно, лишь бы R-7 выполнялся |
| функционал | полный | **полный без исключений** (R-12): ни одна функция не исчезает, ни одно требование не выполняется удалением |

## Незыблемое (проверяется моими прогонами)

1. Палитра — ТОЛЬКО `game/assets/skins/neuro/skin.json`. Слова вместо значков; без эмодзи;
   инлайн SVG/CSS; **без `<script>`**, без `http(s)`-ресурсов.
2. Кадры **1600×1200** и **390×844**; контейнер кадра ровно 1600×1200.
3. Доска целиком: **≥40 клеток-элементов** в разметке.
4. Строки сцены, имена и деньги — **дословно** из `design/variants/scene-data.md`.
5. Пять фактов хода видны: чей ход, фаза, кубики с суммой, наличные всех четырёх мест, последнее событие.
6. Замеры в отдельном файле: **R-1** (пустые ячейки 40×30 ≤ 25 %), **R-2** (занятость внутри кольца
   ≥ 70 %), **R-17** (клетка ≥ 77 px), **R-7** (glance-элементы: `eff = px × 390 / 1600` ≥ 12 px).
   Для каждого glance-элемента укажите, ГДЕ он живёт и почему оттуда читается.
7. Раскадровки **11 событий** (ход, бросок, покупка, аренда, аукцион, сделка, стройка, залог,
   банкротство, конец игры, пауза): 3–6 кадров на событие + таблица «событие → что двигается →
   длительность из `design/tokens.json` → что видно при выключенных анимациях».
8. Приёмка: `py -3.12 design/variants/tools/check_variants.py <файл>` — 22/22.

## Что показать в замерах дополнительно

- **Сколько площади отдано доске** и за счёт чего (панно, панели) — числами: клетка в px, площадь
  нутра кольца, сколько px у панно было и стало, какие кегли в панно стали меньше и почему это
  безопасно (glance-роли там больше не живут или живут с полом).
- **Карту «кто где живёт»** после перераспределения: какая функция в какой области и какого размера.

## Пять направлений нового набора (различаться устройством, а не цветом)

1. **Кольцо во весь кадр.** Кольцо занимает почти весь экран, в центре — узкий хаб (дёшево по
   площади, мелкий кегль), glance-роли переезжают в **четыре угловые клетки кольца**, которые шире
   остальных по замыслу.
2. **Телеграф-полоса.** Кольцо максимум, glance-слой — **единая полоса-тикер по низу кадра** крупным
   кеглем (чей ход · фаза · раунд · банк · последняя строка журнала), панно сведено к узкой ленте.
3. **Доска + боковое табло.** Кольцо ~70 % ширины на всю высоту, справа — **колонка-табло** (крупные
   числа и имена, журнал, места), в центре только кубики и сумма.
4. **Рамка-оверлей.** Кольцо во весь кадр, glance — **лента по внутренней кромке кольца** (сверху и
   снизу), центр сведён к минимуму; клетки крупные, состояния читаются формой.
5. **Углы-эфир.** Кольцо во весь кадр, **четыре угла — «эфирные» клетки-экраны** (чей ход, фаза,
   кубики, банк), остальные клетки крупные; панели сжаты до узких полос по краям.
