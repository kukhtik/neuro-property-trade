# v6 — полный интерактивный прототип на базе `vA-neuro__space-bunny-free`

Основа — макет **`space-bunny` (палитра neuro)**, выбранный владельцем. Доведён до прототипа,
в котором работают зум, сворачиваемые меню, все экраны, арт-система и анимации событий.

| «эмодзи не использовать» | ни одного эмодзи и ни одной односимвольной подписи; из символов только `— • • … →` |

## Найденный и исправленный дефект прототипа

Сгенерированный файл падал при загрузке: `TypeError: Cannot read properties of null (reading
'addEventListener')` на строке 1712. Причина — четыре кнопки шапки были размечены как
`data-od-id="btn-…"` **без `id`**, а скрипт ищет их через `document.getElementById`. Первое же
обращение бросало исключение и обрывало остальную инициализацию: зум, вкладки, демо событий
оставались мёртвыми, хотя разметка выглядела целой. Починка — добавлены `id` четырём кнопкам
(`btn-screens`, `btn-settings`, `btn-rules`, `btn-restart`); после неё ошибок ноль, и все проверки
выше проходят. Резервная копия до правки: `v6-prototype.html.bak` в папке проекта OpenDesign.

## Что не сделано (честно)

- Это **HTML-прототип**, а не реализация в Godot: шаги 2–6 §7 брифа (панно центра в
  `board_scene._place_centre`, переезд рейлов, кегли из `LayoutProfile`, гейты `FILL` /
  `PANEL-NOT-EMPTY`) ещё не начаты.
- Компакт-профиль 880×600 проверен только заявлением автора — отдельного замера на этом профиле нет.
- Анимации проверены как «кадры различаются и демо идёт», а не глазами: насколько каждый жест
  читается, судить владельцу.
- В прототипе один зафиксированный кадр партии (раунд 7, ход Хоста, кубики 5+3): это не живая игра.
