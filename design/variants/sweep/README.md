бесплатным моделям opencode по 2 вариации, делают через OpenDesign».

вариация **A — скин `neuro`**, вариация **B — скин `classic`**.

## Почему часть прогонов умирала и что это лечит

Диагноз: не «провайдер вернул пустоту», а сторож демона —
`Agent stalled without emitting any new output for 600s … terminal_trigger: inactivity_watchdog`.
Бесплатная модель, которой велено выдать весь HTML одним выдохом, уходит в размышление и не
печатает ничего дольше 10 минут → ран убивается.

Лечение (внесено в шаблоны промптов на ходу, живые волны не тронуты): **писать файл шестью шагами**
(каркас+CSS → шапка и доска → «Бросок»/«Событие» → «Игроки»/«Журнал» → остальные панели → notes).
Каждый шаг — отдельный вызов записи, то есть вывод и сброс сторожа. После этой правки 6 из 8
годных файлов получены без падений.

Второе, что стоит помнить: **`od run start` возвращает exit 0 даже упавшему прогону** —
доказательство только строка `DONE <файл> <байты>` и наличие файла.

## Замеры — как повторить

```bash
S=design/variants/tools
py -3.12 $S/render_variants.py design/variants/sweep/renders design/variants/sweep/v[AB]-*.html
py -3.12 $S/measure_fill.py --bg "#0b0613" design/variants/sweep/renders/v[AB]-*.png
py -3.12 $S/check_variants.py design/variants/sweep/v[AB]-*.html
py -3.12 $S/glance_probe.py design/variants/sweep/v[AB]-*.html
```

**Ограничения замера (те же, что и в `design/variants/README.md`):** R-1/R-2 — про топологию
(«нет участка без графики»), а не про долю пикселей смысла; R-2 считается по геометрии кольца из
DOM (контейнер с 40 детьми), а не по цветам клеток; кегли нормированы на канву 1600×1200 (≥20 px),
а не на 1920×1080 из брифа; статическая проверка ищет 4 строки журнала и точные суммы, поэтому
17–18 из 22 у части макетов — это иная формулировка строк, а не обязательно дефект. Смотреть глазами
обязательно: числом «0 % пустых» нельзя доказать, что экран **понятен**.
