## 4. Что нашлось ПРИ закрытии долгов (и чем закрыто)

**Дефекты продукта:**
1. Экран приглашения ставил `Label.selection_enabled` — такого свойства у `Label` нет (проверено по
   списку свойств движка: `Label -> []`, `RichTextLabel -> selection_enabled`). Итог: `SCRIPT ERROR`
   на каждой строке ссылки, а обещанное «выделить и скопировать руками» не работало вовсе. Закрыто
   `UiTheme.selectable_text()` (RichTextLabel с тем же токеном цвета и метрикой размера), найден
   гейтом SG-07, коммит `ec67ac6`.

**Дефекты проверок (из-за них «зелёное» ничего не значило):**
2. `side_by_side.py` сравнивал сегодняшний макет с прошлосуточной сборкой (`build/smoke/admin.png`) и
   падал с ПУСТЫМ текстом ошибки. Теперь `--app`/`--started` (стейл-кадр = жёсткий отказ), и каждый
   отказ называет причину и путь.
3. Захват кадра SG-07 висел на `await RenderingServer.frame_post_draw`: окно, которое ОС перестаёт
   композитить, сигнала не посылает — прогон умирал без вердикта, а гейт звал это «окружением» и
   молча терял пять состояний. Теперь кадр читается без ожидания сигнала + сторожевой таймер в сцене,
   а «кадры были, вердикта нет» = ПРОВАЛ, не SKIP.
4. Захват гонялся с часами: окно решения человека по умолчанию 30 с, поэтому ход доигрывал таймер
   («roll -> absent»: кнопки уже исчезли), а обход занимал 148 с. Теперь `turn_timer = 0` (собственное
   значение движка «без таймаута») — обход 26 с, и на кадре именно ход человека.
5. Префлайт «машина пуста» в SG-10 искал СЛОВА в командной строке: любая обёртка, упоминавшая
   `godot` (собственный мониторинг), считалась конкурирующей игрой, и здоровый замер пропускался за
   1.09 с. Теперь матч по ИМЕНИ процесса (`NeuroPropertyTrade.exe`, `Godot_*.exe`, python с `serve.py`).
6. SG-10 мог опубликовать «регрессию» из окна, которое просто перекрыли. Теперь низкое число обязано
   заслужить это слово: пик ≥40, или окно не в фокусе, или <5 fps в первую секунду = НЕДЕЙСТВИТЕЛЬНО
   (SKIP с причиной); краснеет только устойчиво медленная сборка.
7. **Не было команды пересборки свежих артефактов.** Правило «пересобирать после каждого коммита,
   трогающего `game/`» жило в тексте, а `build/current/*` были экспортированы руками: первый же мой
   коммит в `game/` сделал их стейлом, и HG-11 покраснел — правильно. Появился
   `tools/ci/build_current.sh`; вердикт читается ПО ФАЙЛАМ (неудачный экспорт оставляет старый
   артефакт и всё равно выходит 0).
