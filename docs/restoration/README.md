## Железные правила работы (нарушение = провал задачи)

1. **`exit 0` ничего не доказывает.** Вердикт — по строкам вывода: `ran NNN tests, 0 failed`,
   `ALL TESTS PASSED`, `==> ORACLE PASSED`, отсутствие `SCRIPT ERROR` / `Failed to load script`.
2. Бинарь Godot — **только** через `G="$(tools/ci/godot_bin.sh)"`. `$PWD/tools/ci/godot_bin.sh`
   запускает сам скрипт (напечатает путь, выйдет 0, шаг зелёный впустую).
3. `tools/ci/*.sh` — режим `100755`, иначе CI падает «Permission denied».
4. YAML — валидировать до push (`python -c "import yaml;yaml.safe_load(open(f))"`).
5. **Артефакт и кадр пересобираются в том же прогоне, который о них отчитывается.** Стейл =
   провал. Проверка: `stat` артефакта против времени последнего коммита, трогавшего `game/`.
6. Замер без указания обстановки не публикуется (для FPS — только `tools/fps_clean.py`).
7. **`MIN_TESTS` не понижается.** Понижение допустимо только вместе с объяснением в теле коммита,
   и в том же коммите — план возврата.
8. Коммит на задачу; сообщение объясняет **почему**; выводы команд — в сообщении, не в обещаниях.
9. Никаких «сделано/зелёно» по памяти или из документа — только свежий прогон в этом сеансе.
10. Ядро — авторитет; UI только читает проекции и шлёт интенты через fail-closed `push_intent`.
    Детерминизм и формат событий не трогать; богатые тексты — через существующий `EventAdapter`.

## Как всё запускать

```sh
G="$(tools/ci/godot_bin.sh)"

bash tools/ci/run_tests.sh                 # оракул (импорт-проход обязателен)
bash tools/ci/run_probes.sh                # поведенческие пробы (сейчас 3)

# свежий веб-экспорт и три браузерных проверки (все три сейчас КРАСНЫЕ — это и есть P0):
"$G" --headless --path game --export-release "Web" "$(cd build && pwd -W)/web_probe/index.html"
NPT_WEB="$(pwd -W)/build/web_probe" py -3.12 tools/ci/browser_seat_e2e.py
NPT_WEB="$(pwd -W)/build/web_probe" NPT_REPORT="$(pwd -W)/build/smoke_v3probe" \
  NPT_MOCKUP="$(pwd -W)/design/ui-prototype.html" py -3.12 tools/ci/smoke_all_roles.py

# диагностика аудита (сиды будущих гейтов):
"$G" --headless --path game res://tools/compact_probe.tscn          # профили/достижимость
"$G" --headless --path game res://tools/console_actions_probe.tscn  # кнопки консоли vs движок
"$G" --headless --path game res://tools/admin_smoke_probe.tscn       # админ-панель собирается

# ядро:
"$G" --headless --path game --script res://tools/soak_cli.gd -- --sweep 6 --seed 7777 --turns 250 --players 4
python tools/fps_clean.py                  # FPS (только на чистой машине)
python tools/ci/compare_mockup.py neuro    # дизайн-гейт (см. оговорки в gates.md)
```

**Не трогать** `build/web/` (15:33) и `build/windows/*.exe` (15:22): это единственные
артефакты с работающими экранами старого UI; они нужны как эталон «как выглядит рабочий
джойн», пока не пересобран новый. Свежие экспорты кладём рядом (`build/web_probe/` и т.п.).
