# План работ: я + два beam-субагента (эксперимент «ускорить, не потеряв качество»)

Дата: 2026-10-19. Владелец заказал эксперимент: веду работу я, а рутинную часть забирают
субагенты на **beam** (`delegation.model: beam:cloud`, провайдер `ollama-cloud`,
`max_concurrent_children: 2` — это уже стоит в конфиге профиля `monopoly`).

## 1. Роли

- **Я (родитель)** — пишу и правлю продуктовый код, запускаю оракул и гейты, коммичу, ставлю
  вердикты. Только я могу сказать «готово».
- **beam-субагент (2 слота)** — берёт работу, которая **не спорит со мной за дерево**:
  1. **измерение** (Python/PIL по готовым артефактам, анализ логов);
  2. **авторство изолированного артефакта** (новый файл пробы/теста/документа в своём пути);
  3. **чтение и сводка** (собрать таблицу, каталог анимаций, разбор внешнего отчёта).

## 2. Почему нельзя «просто два писателя»

Правила этого репозитория делают одновременную правку продуктового кода опасной:

- **Один рабочий каталог.** Два агента правят одни файлы — конфликт и потерянные правки.
- **Godot один.** Оракул, SG-01/02/04/05/11 — прогоны по одному проекту; два одновременно
  мешают друг другу (у нас уже был флейк SG-07 после трёх подряд оконных прогонов).
- **SG-10 требует «чистой машины»**: если рядом живёт чужой процесс Godot, гейт делает SKIP —
  и прогон выглядит зелёным, ничего не проверив.
- **Артефакты и реестры** (build/current, gates.md, MIN_TESTS) — общие точки.

Вывод: **параллелим авторство и измерение, сериализуем запись в продукт и прогоны Godot.**

## 3. Жёсткие рамки задачи для субагента (вставляются в каждый таск)

1. Задача = **артефакт + команда приёмки**. Без команды приёмки задача не выдаётся.
2. Артефакт живёт в **своём пути** (`tools/ci/<name>.py`, `game/tools/<name>_probe.gd`,
   `build/<name>/…`, `docs/specs/<name>.md`) и не пересекается с чужими.
3. **Не запускать Godot**, если это не разрешено явно (проект занят моим прогоном).
4. **Не коммитить.** Коммичу я, после оракула и затронутых гейтов.
5. Субагент отчитывается **реальным выводом** своей команды, а не пересказом.
6. Местные грабли передаются в контексте: `py -3.12` (а не `python3`); heredoc с бэкслешами;
   нативные бинари не видят MSYS-пути; `_process(dt) -> void`; `tools/ci/*.sh` — 100755;
   `MIN_TESTS` в `run_tests.sh` растёт на число добавленных тестов.
7. Я **проверяю сам**: запускаю предложенную команду и оракул. Самоотчёт субагента — гипотеза,
   не факт.

## 6. Что даёт ускорение (и что не даёт)

- Даёт: измерение, сбор данных, авторство тестов/проб/документов, подготовка промптов — это
  ~40–50 % времени последних дней, и оно уезжает в параллель без риска для продукта.
- Не даёт: правки UI/движка (один канал), прогоны гейтов (один Godot), приёмку (только я).
- **Мера качества не меняется:** оракул ≥414 тестов, затронутые гейты, негативные проверки для
  новых чеков, никаких «готово» без вывода команды.

## 7. Риски

| Риск | Как снимаем |
|---|---|
| Субагент правит продукт и ломает сборку | в задаче прямо запрещено; его артефакты — в своих путях; проверяю диффом |
| Самоотчёт расходится с реальностью | каждая задача заканчивается командой, которую запускаю я |
| Два Godot одновременно | Godot только у меня; детям — максимум `--check-only` |
| beam не тянет сложную правку | beam даём чтение/авторство/измерение; сложную логику оставляю себе |
| Долгий субагент тормозит очередь | задача ≤ 1 артефакт; при зависании — `action: stop` и делаю сам |
