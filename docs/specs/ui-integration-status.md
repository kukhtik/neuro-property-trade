## Осталось (по плану §9)

1. **Шаг 3 — каркас**: имена узлов = id реестра (`top/seats/stage/board/center/journal/
   inspector/act/toast`), рейлы 46→48px, консоль под доской; после — сверить структуру
   по кадру (доки в `compare_mockup.py` уже сравниваются: сейчас 270/329 при
   макетных 268/344).
2. **Шаг 4 — остальные компоненты**: консоль действий по макету (промпт + primary/secondary
   + место последнего броска), тосты (правый док на широком, строка в консоли на компакте),
   модалки trade-in/build по макету, инспектор, карточки мест.
3. **Шаг 5**: перенести запланированные пробы из `design/coverage.md` в `run_probes.sh`
   (`toast_guard_probe` — тосты не пересекают `stage`/`act`; `settings_tags_probe` — теги +
   тултипы полей), затем перф-замер браузера (≥40 median, `tools/fps_clean.py`, пустая
   машина) после раскладочных правок.
