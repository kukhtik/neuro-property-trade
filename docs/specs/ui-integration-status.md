## Артефакты (после правок)

- `build/web/` пересобран **13.10.2026 15:33** (после ящиков и модалок), `build/windows/*.exe` —
  **15:22** (был суточной давности от 12.10): `--export-release "Web"` требует **абсолютный
  путь** — относительный уходит в `game/build/web` и «успешно» оставляет старый артефакт на
  месте, rc=0. Браузерное место в сквозном смоуке играло именно свежим веб-артефактом.
- **Перф живого сценария — свойство среды, а не UI (A/B одной методикой):** базовая сборка
  `40bc0c7` → браузер median 15 / хост 33; новая (v3) → 16 / 34. Холодная страница у ОБЕИХ —
  ровные **60 fps**, пустая страница в том же Chromium — 60. Chromium рисует на Intel UHD 630
  (ANGLE D3D11; Optimus-ноутбук), план питания «Сбалансированный», фон ~25% (Hermes и агент).
  Порог ≥40 из FIX-02 на этой машине сейчас красный у обеих сборок — числа регрессии UI не
  показывают. Чистый замер (High Performance, пустая машина) — за владельцем.
- `py -3.12 tools/ci/smoke_all_roles.py` (с `NPT_MOCKUP=design/ui-prototype.html`):
  **SMOKE PASSED** — хост + эфир + живое браузерное место в одном прогоне, сравнение с
  макетом зелёное, отчёт `build/smoke/report.html`, кадры `admin/stream/player.png` (1440×900).
- `build/smoke/side_by_side.png` — макет и приложение рядом, пересобран после правок.

## Осталось

1. **Чистый перф-замер ≥40 на пустой машине** (High Performance, без фоновых процессов) —
   по A/B выше низкое число живого сценария наблюдается у обеих сборок; сам UI в холоде
   держит 60. За владельцем.
