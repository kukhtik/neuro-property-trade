# NPT UI — план исправлений (для второго агента)

Репозиторий: `neuro-property-trade`, Godot 4.7.2, ветка `main`.
Точка входа: коммит `1f96bb3`. Разбор причин: `docs/specs/ui-defect-report.md`.

Задачи идут по порядку. **FIX-01 обязателен первым**: без него остальные нельзя проверить
замером.

---

## 0. Правила работы, обязательные в этом репозитории

Они уже стоили проекту времени; нарушение любого из них здесь приравнивается к ошибке.

1. **`exit 0` не доказывает ничего.** Вердикт оракула — по строкам:
   ```
   ran NNN tests, 0 failed
   ALL TESTS PASSED
   ==> ORACLE PASSED (NNN tests, 0 SCRIPT ERROR)
   ```
   Порог числа тестов зашит в `tools/ci/run_tests.sh` (`MIN_TESTS`). Он ловит исчезновение
   целого модуля, а не падение одного теста.
2. **Скрипты `tools/ci/*.sh` обязаны быть `100755`.** CI зовёт их как исполняемые; при
   `100644` шаг падает «Permission denied».
3. **Бинарь Godot — только через `G="$(tools/ci/godot_bin.sh)"`.** Он не в `PATH`.
   Вызов `$PWD/tools/ci/godot_bin.sh` запускает **сам скрипт**: тот напечатает путь,
   проигнорирует аргументы и выйдет с нулём. Шаг зелёный, работы ноль.
4. **YAML валидируется до push:** `python -c "import yaml;yaml.safe_load(open(f))"`.
   Оба workflow уже падали за 0 секунд без логов из-за отступа в блоке `run: |`.
5. **Артефакт пересобирается, иначе правка не существует.** `.exe` и `build/web/`
   в репозитории не пересобираются сами. Проверять временем сборки против времени правки:
   ```sh
   stat -c '%y %n' build/windows/NeuroPropertyTrade.exe
   git log -1 --format='%cd' --date=format:'%Y-%m-%d %H:%M' -- <файл>
   ```
6. **Замер без указания обстановки не публикуется** (§FIX-02).
7. **Коммит на задачу**, сообщение объясняет **почему**, а не «что».

## FIX-01. Разделить фабрику меток по назначению

**Симптом:** текст «полетел почти везде», в браузере 44 -> 20 FPS.

**Файл:** `game/ui/theme.gd:113–127`.

**Сейчас:**

```gdscript
static func label(text: String, size: int = -1, color: Color = Color.TRANSPARENT) -> Label:
	...
	l.autowrap_mode = TextServer.AUTOWRAP_WORD_SMART      # навязано ВСЕМ
	l.size_flags_horizontal = Control.SIZE_EXPAND_FILL    # навязано ВСЕМ
	return l
```

**Замеренная цена** (`game/tools/label_cost_probe.tscn`, 40 строк журнала, 200 проходов):

```
с auto-wrap + expand-fill:   18.9 мс
без правки:                   5.2 мс
отношение:                    3.60 x
```

**Задача.**

1. `label()`, `label_muted()`, `label_money()` — **значения**: перенос `AUTOWRAP_OFF`,
   ширина по содержимому (`SIZE_SHRINK_BEGIN`), растяжения нет.
2. Добавить `label_wrap(text, size, color)` — **абзацы**: `AUTOWRAP_WORD_SMART` +
   `SIZE_EXPAND_FILL`.
3. Перевести на `label_wrap` только те места, где текст действительно абзац:
   описания в `tile_inspector`, строки правил, подсказки действий, текст приглашения.
   Ориентир — 17 меток внутри горизонтальных строк остаются однострочными:
   `ui/players_panel.gd` (7), `ui/top_bar.gd` (4), `ui/journal_panel.gd` (4),
   `ui/tile_inspector.gd` (2).

**Критерий приёмки:**

```sh
G="$(tools/ci/godot_bin.sh)"

# 1. цена раскладки вернулась к эталону (допуск +10 % от «без правки»)
"$G" --headless --path game res://tools/label_cost_probe.tscn
#    ожидается: отношение <= 1.10

# 2. частота кадров в браузере восстановлена
python tools/fps_clean.py
#    ожидается: БРАУЗЕР median >= 40   (эталон до регрессии — 44)

# 3. пропорция колонок не поехала
python tools/ci/compare_mockup.py neuro
#    ожидается: колонки 1.21

# 4. оракул
bash tools/ci/run_tests.sh
```

**Запрещено:** откатывать `3d6928c` целиком. Перенос в рейках — настоящая потребность
(жалоба «текст столбиком» была верной); его закрывает `label_wrap`, а не откат.

## FIX-02. Сделать перф-замер доказательством, а не ритуалом

**Файл:** `tools/fps_clean.py` (создан, работает).

**Задача — доделать три вещи:**

1. **Предполётная проверка.** Падать до старта, если на машине жив процесс игры или
   `serve.py`. Иначе число меряет конкуренцию машины с собой.
2. **Флаги против троттлинга** — уже стоят:
   `--disable-background-timer-throttling --disable-backgrounding-occluded-windows
   --disable-renderer-backgrounding`. Без них фоновое окно читается как **1 FPS**
   (проверено: один такой замер дал median=1, max=4 — это артефакт, не дефект).
3. **Печатать `document.visibilityState`** рядом с числом — уже есть.
4. **Код возврата `1`, если браузер < 30 median.** Тогда регрессию ловит прогон, а не глаз.

**Критерий приёмки:** прогон с искусственно запущенным лишним хостом завершается кодом `1`
с внятным сообщением, а не выдаёт «нормальные» цифры.

## FIX-04. Гигиена раскладки: 40 предупреждений

```
Nodes with non-equal opposite anchors will have their size overridden after _ready().
```

**Замерено: 40 и с правкой, и без неё** — то есть не регрессия `3d6928c`, а унаследованное.
Но предупреждение означает, что заданный размер **молча игнорируется**: раскладка живёт не
так, как записана. Это и есть «интерфейс разъезжается».

**Задача:** найти узлы с full-rect anchors внутри контейнера. Либо вынести из контейнера,
либо не задавать anchors — контейнер сам расставит.

**Критерий приёмки:** `0` таких предупреждений в прогоне проб.

## FIX-05. Закрепить правило i18n

Журнал переводит **span адаптера**, а не тип события движка:

```
движок: free_parking  ->  EventAdapter.TYPE_MAP  ->  "park"  ->  I18n.t("event_type.park")
```

Ключ `event_type.free_parking` не запрашивается никогда. Из-за этого коммит `94841d4`
добавил 16 меток, которые никто не читал, и проблема осталась; починил её только `1f96bb3`.

**Задача:** проба уже написана — `game/tools/journal_text_probe.tscn`. Подключить её к
`tools/ci/run_probes.sh`, чтобы она шла в CI.

**Критерий приёмки:** добавление нового span в `TYPE_MAP` без метки в `data_event.gd`
даёт красную сборку. Сейчас проходит: 36 строк интерфейса.

## Порядок и отчётность

```
FIX-01  ->  FIX-02  ->  FIX-03  ->  FIX-04  ->  FIX-05  ->  FIX-06
   |           |           |           |           |
   |           |           |           |           +-- одна проба на скин
   |           |           |           +-- 0 предупреждений
   |           |           +-- лог читаемый
   |           +-- регрессия ловится прогоном
   +-- замер цены падает до эталона, браузер >= 40
```

Каждая задача — отдельный коммит с прогоном оракула. В сообщении коммита — замер
до и после, а не описание намерения.

**Определение готовности:** все четыре критерия FIX-01 выполнены **одновремено** на одном
и том же коммите, и артефакты (`.exe` и `build/web/`) пересобраны **после** него.
