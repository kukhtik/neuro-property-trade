## Коротко о сути

Регрессию внесла одна правка (`game/ui/theme.gd`, коммит `3d6928c`): фабрика меток
`UiTheme.label` начала навязывать перенос строк и растяжение **каждой** метке проекта —
86 мест вызова в 13 файлах.

Следствия, оба замерены:

- **Раскладка:** метки внутри горизонтальных строк потянули свободную ширину и вытолкнули
  соседей — «интерфейс развалился», «текст полетел».
- **Частота кадров:** раскладка подорожала втрое. Браузерная сборка однопоточная, поэтому
  она это чувствует напрямую: **44 -> 20 median**. Нативный `.exe` поглощает (46–60).

Жалоба, из которой правка выросла («текст выстраивался в узкую вертикаль»), была
**верной** — поэтому откатывать коммит целиком нельзя. Нужно разделить две роли текста:
значения не переносятся, абзацы переносятся.

## Что проверено и оказалось НЕ дефектом

Чтобы не чинили несуществующее:

- `exit 0` оракула, палитра 11/11, 563 ключа i18n в RU и EN, отсутствие дублей ключей.
- 40 предупреждений про anchors — **существовали до правки** (замерено 40 и с ней, и без).
- Хост: в чистом замере 60 FPS на 1440×900. Регрессии в нём нет.

## Отдельно: гигиена замеров

Часть наблюдений владельца («катастрофически упал fps») усилена тем, что на машине
оставались живые тестовые хосты и окна Chromium — машина конкурировала сама с собой.
Плюс Chromium душит `requestAnimationFrame` в фоновом окне до **1 кадра**: один мой замер
дал median=1, и это был артефакт.

`tools/fps_clean.py` теперь проверяет обстановку и падает, если рядом что-то крутится.
Число без указания обстановки публиковать нельзя.

## Воспроизвести замеры

```sh
G="$(tools/ci/godot_bin.sh)"

"$G" --headless --path game res://tools/label_cost_probe.tscn   # цена раскладки
"$G" --headless --path game res://tools/journal_text_probe.tscn  # ключ вместо текста
python tools/fps_clean.py                                        # частота кадров
python tools/ci/compare_mockup.py neuro                          # сверка с макетом
bash tools/ci/run_tests.sh                                       # оракул
```
