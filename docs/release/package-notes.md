# Release package — Neuro Property Trade

Что входит в поставку, как её собрать, как проверить и что в неё сознательно не входит.
Артефакты **не лежат в git** (`.gitignore`: `build/`) — они пересобираются из дерева одной
командой, и это правило, а не удобство: `build_current.sh` в шапке объясняет, что отчёт не
имеет права опираться на сборку старее кода рядом с ней (HG-11).

## 1. Что входит в поставку

Две половины, обе из одного экспорта Godot 4.x:

| Половина | Путь | Что это |
|---|---|---|
| Windows (desktop) | `build/current/windows/NeuroPropertyTrade.exe` | один самодостаточный исполняемый файл: `embed_pck=true` в `game/export_presets.cfg`, поэтому `.pck` внутрь и рядом ничего не нужно |
| Web (браузер) | `build/current/web/index.html` | точка входа веб-сборки; остальные файлы каталога грузятся ею |

## 2. Как собрать

```bash
tools/ci/fetch_godot.sh        # один раз: закреплённый Godot, sha512-проверка
tools/ci/build_current.sh      # обе половины (--windows / --web — по одной)
```

Скрипт чистит прошлый `.exe` и `index.html`, делает обязательный `--import` (класс-кэш для
`class_name`), экспортирует пресеты «Windows Desktop» и «Web», и **читает вердикт из
файлов**, а не из кода возврата экспорта: упавший экспорт оставляет прошлый артефакт на
месте и всё равно выходит с 0. Веб-половина дополнительно прогоняется через
`tools/ci/verify_web_build.sh` — сборка, которая не грузится, считается провалом.

## 3. Как проверить

```bash
tools/ci/run_tests.sh        # оракул: headless-сьют, порог MIN_TESTS (428), ноль SCRIPT ERROR
tools/ci/run_gates.sh        # реестр гейтов, отчёт в build/gates/
tools/ci/scenario_s3.sh      # релизная веб-сборка в настоящем Chromium на 1280x720 и 390x844
```

Вердикты читаются строками, не кодом возврата:

- `run_tests.sh` — строка `ALL TESTS PASSED` плюс число тестов не ниже `MIN_TESTS`
  (по умолчанию 428, задаётся переменной окружения) плюс отсутствие `SCRIPT ERROR`.
  Код возврата один ничего не значит: раннер пропускает неразобранный модуль и всё равно
  выходит с 0 — ровно поэтому порог по числу и существует.
- `run_gates.sh` — по строке на гейт (`==> HG-XX PASSED` / `==> HG-XX FAILED: причина`) и
  итог `==> GATES PASSED (...)`. Код возврата Godot — шум (на Windows он падает при
  очистке). Карантинные гейты печатаются, но раннер не валят.
- `scenario_s3.sh` — последняя строка: `==> S3 PASSED (...)` или `==> S3 FAILED: причины`.
  Экспорт делает сам этот прогон, свежесть `index.pck` сверяется со временем старта, так
  что старая сборка пройти не может.

Приёмка самого пакета — `bash tools/ci/gates/acceptance_gate.sh` (12 обещаний, DONE/TODO).

## 4. Манифест

Список ровно того, что производит `build_current.sh`; ничего, чего в каталогах нет, здесь
не перечислено.

### `build/current/windows/`

| Файл | Что это |
|---|---|
| `NeuroPropertyTrade.exe` | релизный экспорт Windows с вложенным `.pck` (движок + данные игры в одном файле) |

### `build/current/web/`

| Файл | Что это |
|---|---|
| `index.html` | точка входа: канвас, мета-теги, ссылки на иконки, подключение `index.js` |
| `index.js` | загрузчик Godot: поднимает WebAssembly-движок и подаёт ему данные |
| `index.wasm` | движок Godot, скомпилированный в WebAssembly |
| `index.pck` | упакованные данные игры (сцены, ресурсы, скрипты) |
| `index.png` | картинка на время загрузки |
| `index.icon.png` | иконка вкладки (`rel="icon"` в `index.html`) |
| `index.apple-touch-icon.png` | иконка для iOS (`rel="apple-touch-icon"`) |
| `index.audio.worklet.js` | аудио-ворклет браузера |
| `index.audio.position.worklet.js` | ворклет позиции аудио |

### Размеры и хеши

Намеренно не вписаны: они протухают на следующей пересборке, а манифест, который врёт о
хеше, хуже манифеста без хеша. Пересчитать самому — одна команда на каталог:

```bash
sha256sum build/current/web/* build/current/windows/*.exe
stat -c '%s bytes  %n' build/current/web/* build/current/windows/*.exe   # размеры
```

Без `sha256sum` (чистый cmd): `certutil -hashfile build\current\windows\NeuroPropertyTrade.exe SHA256`.

## 5. Notes — что не включено и какие ограничения

- **Тестовые модули в пак НЕ попадают.** Гейт C3 в `acceptance_gate.sh` ищет строку
  `res://tests/` внутри `build/current/web/index.pck` и требует ноль совпадений; замер:
  **0**. Экспорт исключает `game/tests/` (`exclude_filter="tests/*"` в
  `game/export_presets.cfg`), пак 1.25 МБ → 1.08 МБ. Оракул при этом работает из
  ДЕРЕВА (`godot --script res://tests/run.gd`), а не из пака, поэтому исключение не
  ломает проверку; `res://tools/replay.gd` — продукт, он в паке остался.
- **Заявка на `vedal.ai/projects` в пакет не входит.** Она вне дерева и подаётся только
  владельцем (`docs/program.md`, A7). Пакет — приложение к ней, не замена.
- **Узкое окно.** Контракт раскладки — `MIN_WIDTH = 880` (`game/ui/core/layout_profile.gd`).
  Окно 390 px (телефон) не поддерживается: проба `phone_fit` измеряет переполнение
  (раскладка ~817 px в окне 390 px) и держится в карантине с инвертированным ожиданием.
  Читаемость стрима с телефона — другое обещание, его меряет STREAM-READ (порог 12 px).
- **Живой Neuro и живой Twitch в пакет не входят.** SDK-место проверено против мока
  (`tools/ci/mock_neuro_ws.py`, гейт HG-08), место чата — без сети и без токена (CHAT-01).
  Живой сервер задаётся `NEURO_SDK_WS_URL`, живой IRC требует `NPT_TWITCH_TOKEN` в
  окружении — оба значения принадлежат владельцу.
- **Пакет — снимок дерева на момент сборки.** Код, ушедший вперёд, делает артефакт
  старым; пересобрать `tools/ci/build_current.sh` дешевле, чем объяснять расхождение.
- Подробный список ограничений и передачи — `docs/acceptance/handoff-neuro-property-trade.md`.
