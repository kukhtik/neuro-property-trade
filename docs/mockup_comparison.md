# Сверка результата с макетом

Два инструмента, **разные вопросы**:

| Инструмент | Вопрос | Ответ |
|---|---|---|
| `compare_mockup.py` | «реализованы ли объявленные значения?» | **гейт**: палитра, пропорции, структура |
| `side_by_side.py` | «похоже ли это?» | **картинка**: макет и результат рядом |

## 1. Значения (гейт)

```sh
python tools/ci/compare_mockup.py neuro     # или evil
```

Макет — это не картинка, а спецификация, и он несёт свой дизайн в машиночитаемом виде.

| Ось | Макет объявляет | Приложение | Сверка |
|---|---|---|---|
| **Палитра** | `:root[data-theme="neuro"]` | `skin.json` → `tokens.color` | по значению |
| **Колонки** | `--L:272px --R:330px` | измеряются по кадру | по **пропорции** |
| **Структура** | `top mid pl stage jr act` | те же полосы в кадре | по наличию |

Пропорция, а не пиксели: приложение работает в 1440 px, адаптивная раскладка сохраняет
**отношение**, не абсолют.

### Замер

```
палитра     11 из 11 токенов, Δ=0 (байт в байт)
колонки     макет 272/330 = 1.21   приложение 239/290 = 1.21
структура   6 из 6 регионов
```

## 2. Картинка (для глаза)

```sh
python tools/ci/side_by_side.py neuro
```

Открывает макет в браузере, ставит ему `data-theme="neuro"`, снимает кадр в **том же
разрешении, что у приложения** (1440×900), и кладёт оба рядом.

**Порога «похоже» не существует.** Разные рендереры, шрифты, масштабы — любое число здесь
было бы выдумкой. Инструмент выдаёт изображение и на этом останавливается. Это осознанное
ограничение, а не недоделка.

Замечено глазами и стоит знать: макет свёрстан **с полями** по краям, приложение занимает
экран целиком. Это видно на картинке и не является ошибкой ни того, ни другого.

## Ошибки в пробах, найденные по ходу

**1. Имена токенов читались с дефисами.** Регулярка захватывала `--bg` вместо `bg`, и все
11 сравнений давали «не найдено», хотя цвета совпадали точно.

**2. Границей панели считался `x=0`** — рамка окна, у которой нет поля с одной стороны.
Отсюда «ширина панели 0px».

**3. Искались не те регионы.** Я искал `id="left"`, `id="board"`, а макет называет их
семантически: `pl`, `stage`, `jr`.
