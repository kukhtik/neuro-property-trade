# Как играть с другими людьми

Три способа. Выберите по ситуации:

| Способ | Кому подходит | Что нужно |
|---|---|---|
| **A. Локально** | все за одним компьютером | только игра |
| **B. По сети (LAN / интернет)** | у каждого свой компьютер | один хост + адрес |
| **C. В браузере** | у друзей нет игры | хост + веб-сборка |

Во всех случаях движок один: **партия живёт на компьютере хоста**, остальные только присылают
свои ходы. Ведущий не может «подкрутить» игру в свою пользу, а игрок — сломать состояние:
движок проверяет каждый ход.

---

## A. Локально (самый простой)

Двое-четверо за одним компьютером.

1. Запустите игру.
2. В меню настройки партии задайте число мест.
3. У нужных мест выставьте драйвер **LOCAL** (человек за этим компьютером).
4. Начните партию. Ход переходит по очереди, активного игрока видно в шапке и в панели игроков.

Для стрима есть отдельный режим — см. «Роли» ниже.

---

## B. По сети — у каждого свой компьютер

Один компьютер **хост**, остальные подключаются к нему.

### На компьютере хоста

1. В меню настройки **выберите места с драйвером `REMOTE`** — сколько друзей будет играть.
2. **Включите сетевой режим.** По умолчанию сервер слушает только сам себя
   (`127.0.0.1`), поэтому другие машины его не увидят. Нужно открыть его наружу:

   ```bash
   # из папки с игрой
   godot --path game -- --server-bind=0.0.0.0 --server-port=9080
   ```

   `0.0.0.0` = «слушать на всех сетевых интерфейсах». Порт можно любой свободный.

3. **Найдите адрес для друзей.** Игра напечатает в консоль:

   ```
   SERVER ready ws://192.168.1.42:9080
   SERVER seat=1 token=a3f9c2  ← по одной строке на каждое удалённое место
   ```

   Адрес выводится **реальный LAN-адрес**, а не `0.0.0.0` (по нему нельзя подключиться).

4. **Передайте каждому другу его личный токен.** Токенов столько, сколько мест `REMOTE`.

> **Безопасность.** Токен — это и есть приглашение: кто его знает, тот займёт это место.
> Не публикуйте их открыто. `--server-bind=0.0.0.0` открывает порт всей сети, в которой вы
> находитесь (в том числе гостевому Wi-Fi). Для игры с друзьями по интернету адрес и порт
> придётся пробросить на роутере либо использовать туннель (например, `ssh -R` или любой
> сервис проброса) — тогда `0.0.0.0` не нужен, достаточно `127.0.0.1`.

### На компьютере друга

Запустите игру так (адрес и токен — свои):

```bash
godot --path game -- --seat=a3f9c2 --host=ws://192.168.1.42:9080
```

Игра откроется **сразу в партии**, в своей роли. Управление — кнопками внизу; горячие клавиши
`B` — купить, `N` или `End` — завершить ход.

### Если не подключается

| Симптом | Причина |
|---|---|
| «не удалось подключиться» у друга | хост запущен без `--server-bind=0.0.0.0` |
| в консоли хоста `ws://127.0.0.1:…` | то же: это адрес «только я» |
| адрес есть, но связи нет | брандмауэр хоста; разрешите игре входящие |
| подключился, но «место занято» | токен уже использован или чужой |
| по интернету не идёт | нужен проброс порта на роутере или туннель |

## C. В браузере — друзьям ничего не нужно

Хост запускается как в способе **B**, а друзья открывают **ссылку**. Игра сама читает адрес и
токен из URL.

1. Соберите веб-версию (или возьмите готовую из артефактов GitHub Actions → `web-build`).
2. Раздайте папку по HTTP. **Обязательны заголовки COOP/COEP** — без них браузер не запустит
   wasm:

   ```
   Cross-Origin-Opener-Policy: same-origin
   Cross-Origin-Embedder-Policy: require-corp
   ```

   Быстрый способ для проверки — любой статический сервер с этими заголовками; для игры с
   друзьями через интернет нужен хостинг, который их отдаёт (GitHub Pages их **не** отдаёт).

3. Друг открывает:

   ```
   https://ваш-хост/index.html?seat=a3f9c2&host=ws://192.168.1.42:9080
   ```

4. Замечено ограничение: **доска в браузере сейчас не прорисовывается** — клиент играет
   (ходы проходят, состояние приходит), но поле показывается пустым. Играть за столом проще
   способом **B**; браузер годится, чтобы дать другу место, пока доска в нём не доделана.

## Роли: игрок, стрим, админ

Роли выбираются **при запуске**, а не кнопкой в интерфейсе — так задумано.

| Роль | Флаг | Что это |
|---|---|---|
| **Игрок** | веб-сборка или `--seat/--host` | обычное место в партии |
| **Стрим (OBS)** | `--stream` | компактный кадр для зрителей |
| **Админ** | `--admin` | полный интерфейс + панель управления по `F12` |

Роль **стрима** можно вывести в OBS как отдельный источник: она показывает то же поле, но без
служебных элементов.

## Как играть: правила

Настольная игра с механикой Monopoly, оригинальное оформление.

- Стартовый капитал, стоимость клеток и дома — задаются в меню настройки.
- **Дома строятся только на полной монополии** (все клетки одной группы).
- Торги между игроками разрешены (можно выключить).
- Есть правило «**Банк парковки**» — включается в настройках, по умолчанию выключено.
- **Лимит раундов** (в настройках, по умолчанию выключен): после N раундов партия кончается и
  побеждает **самый богатый**. Нужен потому, что без него партия может не кончиться никогда —
  если никому не собрать монополию, дома не строятся, аренда мизерная, а банк платит за проход
  GO. Обычная партия кончается за **19–45 раундов**; лимит **60** покрывает её с запасом.

Настройки живут **на хосте** — то, что выбрал ведущий, действует для всех.

## Быстрая проверка перед игрой

```bash
tools/ci/run_tests.sh     # движок: 406 тестов
tools/ci/run_probes.sh    # интерфейс: 16 проверок
```

Обе должны завершиться зелёным. Если игра ведёт себя странно, сначала прогоните их — они
покрывают правила, оформление и сеть.
