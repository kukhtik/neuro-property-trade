# Промпт для OpenDesign — новый интерфейс «Neuro Property Trade»

Ты — старший UI/UX-архитектор и арт-дизайнер игровых интерфейсов. Спроектируй и визуально
оформи новый интерфейс настольной игры «Neuro Property Trade» (оригинальный клон Monopoly,
движок Godot 4.7, GDScript, тёмная тема, стримовый проект Neuro-sama). Твоя задача — НЕ писать
GDScript и НЕ делать код. Ты выдаёшь полную визуальную концепцию + макеты всех экранов и
панелей (по одному экрану достаточно, чтобы собрать интерфейс в OpenDesign), с точной
спецификацией компоновки, типографики, палитры, состояний и поведения. Всё ниже — жёсткие
требования заказчика. Соблюдай КАЖДЫЙ пункт, не заменяй его на своё видение без явной оговорки
в ответе.

## 0. ЧТО ТАКОЕ ИГРА (обязательный контекст)

«Neuro Property Trade» — Monopoly-подобная экономическая настольная игра с одним авторитетным
движком и несколькими «местами» (seat) за столом: локальный человек (LOCAL), AI, чат (CHAT),
Neuro и «evil» через Neuro-SDK. Игроки бросают кубики, обходят кольцо клеток, покупают тайлы,
строят дома/отели, платят аренду/налоги, сидят в тюрьме, торгуются и участвуют в аукционах.
Интерфейс полностью двуязычный (русский/английский), тёмная тема, рассчитан и на стрим (крупные
читаемые элементы), и на веб-зрителя через WebGL.

**Архитектурная жёсткость (не нарушать в дизайне):**
- ОДИН игровой экран. НЕТ отдельного экрана «лобби/главное меню». Доска всегда корневой
  визуальный слой; поверх неё открываются оверлеи (настройки, правила, модалки решений,
  итоги партии, админ-панель).
- Доска ВСЕГДА показывается целиком (полное кольцо, вписано в доступный центр). Панорамная
  «кино-камера» есть, но по умолчанию ВЫКЛЮЧЕНА.
- Центр доски — «сцена»: туда помещаются броски кубиков, карточка текущего решения
  (покупка/аукцион), финальный баннер.
- Скрытый слой администратора (F12) есть ТОЛЬКО у хоста, на WebGL его нет вовсе.
- Интерфейс самомасштабируется под размер окна (5 брейкпоинтов), минимальное окно 900×600.
- Полная локализация RU/EN с мгновенным переключением языка на лету (без пересоздания сцен).

**Брендовые ограничения (лицензионные):** запрещены любые товарные знаки Hasbro/«Monopoly» —
слова CHANCE, Boardwalk, MARVEL, классические фишки/цвета/оформление Monopoly. Используем
оригинальные названия, цвета групп и фишки (перечислены ниже). Игра называется
«NEURO PROPERTY TRADE».

**Цвета групп клеток (полоса группы на тайле), оригинальная не-Hasbro палитра:**

desaturate 0.35 (0.35 * s в HSL) + диагональная штриховка ~20% + тускнеющий бейдж владельца.

**Таймер-кольцо:** цвет по остатку времени — >60% зелёный, 30–60% жёлтый, <30% красный + пульс.

## 2. ШРИФТ И ТИПОГРАФИКА

- Дефолтный шрифт Godot (содержит кириллицу; русский длиннее английского — учитывай в кнопках).
- Базовые размеры: основной текст 14px; вторичный/подписи 12–13px; заголовки панелей 12–14px;
  титул в top-bar 15px; имя победителя в итогах 18px.
- Заголовки в верхнем регистре (ИГРОКИ, КЛЕТКА, ЖУРНАЛ, НАСТРОЙКИ МАТЧА и т.п.).
- Имя тайла: cell ≥ 44px — до 2 строк, авто-fit шрифт 9→13px; cell < 44px (компакт) — 1 строка
  с ellipsis по короткому имени (≤14 симв). Цена тайла — шрифт 7→13px, снизу.
- Деньги всегда с символом `$` и золотым цветом `#ffd34d`.

Правила каркаса:
- **TOP BAR (44px):** слева логотип/титул «● NEURO PROPERTY TRADE» (золотым, 15px). Центр —
  «чип хода» (мини-фишка в гало цвета + имя текущего игрока цветом + фаза по-русски) +
  кольцо-таймер 36px (видно ТОЛЬКО когда у решения есть лимит; нет лимита — скрыто;
  ход SDK-места — вместо таймера текст «ожидание Neuro…»). Справа кнопки-иконки: ⚙ настройки
  (F1), ❓ правила (F2), ⟲ рестарт (F3), 🔊 звук, 👁 наблюдатель (ТОЛЬКО если в матче нет
  LOCAL; иначе иконки нет), 🛠 админ (ТОЛЬКО у хоста; на WebGL её нет).
- **LEFT (мин 200, база 240, панель «ИГРОКИ»):** карточка каждого игрока. Холодное состояние —
  текст «Партия ещё не начата». См. §4.4. Панель имеет заголовок «ИГРОКИ», кнопку «+ добавить».
- **CENTER:** квадрат доски, ВСЕГДА целиком вписан (11×11 грид, cell = min(w,h)/11). Внутри —
  кольцо тайлов (см. §4) + центр-сцена. Центр-сцена: броски кубиков (BG3-анимация), карточка
  текущего решения, баннеры приходят сверху центра, финальный баннер победы.
- **RIGHT (мин 240, база 300):** журнал событий (верх, растягивается, см. §7) + закреплённый
  инспектор клетки (низ, фикс. высота, см. §6). Ширина журнала в режиме наблюдателя — 380px.
- **ACTION BAR (84px):** верхняя строка — контекстный ход (фраза, что от тебя нужно), затем
  первичные кнопки решений (≤5, крупные: БРОСИТЬ КУБ / КУПИТЬ / ПАСС / СТАВКА / ОПЛАТИТЬ /
  КАРТА выхода / НАЧАТЬ ПАРТИЮ). Вторая мелкая строка «ещё:» — вторичные менеджмент-действия
  (торг · стройка · залог · продать дом) — визуально вторичны. Мини-отображение последнего
  броска тоже тут. Инспектор и тосты НИКОГДА не перекрывают панель действий.
- **Холодное (предматчевое) состояние:** доска пустая, фишки на GO; в action bar ОДНА большая
  кнопка «▶ НАЧАТЬ ПАРТИЮ», которая открывает оверлей настроек. Над доской открыт оверлей
  настроек (фокус — на кнопке СТАРТ). ESC → оверлей закрывается без старта (холодная доска +
  кнопка СТАРТ в action bar).

## 4. КЛЕТКИ И ФИШКИ (ДОСКА)

### 4.1 Анатомия тайла (клетка = cell px, всё пропорционально)

```
        КЛЕТКА (фон — тёмный тайл #20252f, светлый текст)
 ┌──────────────────────────────────┐
 │ ▓▓▓▓▓ ГРУППА ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │ ← полоса группы на грани К ЦЕНТРУ (28% cell), родной цвет группы
 │   🏠🏠🏠🏠 или 🏨                  │ ← домики (SVG) НА полосе
 │                                  │
 │        Лесной проспект           │ ← имя: до 2 строк, auto-fit 9..13px
 │                                  │
 │            $100                  │ ← цена (низ, золотом/вторичным)
 └──────────────────────────────────┘
  рамка 2px цветом владельца по периметру + круг-бейдж ⌀12px с инициалом владельца в углу
  У ВНЕШНЕГО края; залог: клетка обесцвечена + диагональная штриховка + тусклый бейдж
```

- Полоса группы — родной цвет группы (НЕ смешивать с цветом владельца — на малых размерах
  сливаются). Владелец — только рамка + бейдж, виден на любом масштабе.
- Углы (СТАРТ/GO, ТЮРЬМА, БЕСПЛАТНАЯ СТОЯНКА, «ИДИ В ТЮРЬМУ») и типы (налог, железная дорога,
  коммуналка, шанс, общество) — крупные SVG-иконки по центру, фон слегка тонируется цветом типа.
- Компакт-режим (cell < 44px): цена скрыта, дома → бейдж «×N»/«H», имя 1 строка с ellipsis по
  короткому имени, поверх гало фишки рисуется инициал.
- Холодная клетка не принадлежащая никому — «— свободен».

### 4.2 Фишки (токены)

- SVG-спрайт фишки (см. §9 ассеты) размером 0.38×cell (мин 20px), БЕЗ перекраски арта; под
  фишкой — цветное гало-круг (радиус 0.52×фишки, цвет игрока из §1). Инициал не обязателен,
  кроме компакт-режима.
- Фишки на ОДНОЙ клетке расходятся веером по дуге 60° вокруг центра клетки (радиус 0.35×cell),
  порядок по pid, не перекрываются.
- Движение — пошаговая анимация между соседними клетками (70 мс/клетка, ease-in-out, фишка
  «идёт»). Проход GO — золотая вспышка. Дубли — короткий доп. прыжок. Тюрьма — фишка за
  решёткой угла. Все анимации отключаются настройкой «анимации: выкл» → мгновенные позиции.

### 4.3 Кубики (центр-сцена, стиль Baldur's Gate 3, ~1.1–1.3 с)

Фазы: spawn (появление scale 0.6→1.0, fade-in) → roll (оба кубика парабола вверх, вращение 720°,
тени) → bounce (2 приземления со squash scaleY 1→0.75→1) → settle (доворот «лицом», короткая
вспышка рамки) → result (крупная сумма «8» над кубиками ~0.6 с; на дубле — золотая рамка + чип
«ДУБЛЬ»; на третьем дубле — штамп «→ ТЮРЬМА»). Текстуры die_1..6.svg. При «анимации: выкл» —
мгновенный показ результата ~0.8 с. Звук: whoosh на roll, клик на каждый bounce.

### 4.4 Карточка игрока (левая панель)

```
┌────────────────────────────────┐
│ (🐙) Host            [$ 1500]  │ ← фишка-аватар в гало цвета; имя цветом игрока
│  @ «Большая шишка» · 9 тайлов  │ ← позиция НАЗВАНИЕМ клетки (НЕ «@11»)
│  🏠 3   💼 1   ⚖ вых.: 1 карта │ ← дома, залоги, карта выхода (бейджи)
└────────────────────────────────┘
  активный ход: рамка акцента 2px + «▶ ход»; тюрьма: бейдж ⚖ с числом попыток;
  away: серый + «авто-пас»; банкрот: зачёркнут и приглушён (dim 0.5)
```

Тултип строки — полный свод (драйвер, деньги, позиция, тайлы, дома, залоги). Клик по строке →
доска мягко подсвечивает клетку игрока (в режиме наблюдателя — начать следить за ним; повторный
клик — отменить). Никаких невнятных аббревиатур («нед.»), только полные слова.

## 5. ОВЕРЛЕЙ «НАСТРОЙКИ МАТЧА» (бывшее лобби, F1)

Полноэкранная модалка поверх живой доски, слоеная НАД ней (отдельный верхний CanvasLayer, layer 50).
Шапка «НАСТРОЙКИ МАТЧА» + кнопки [сброс] [✕ ESC]. 5 вкладок: [Игроки] [Правила] [Темп]
[Интерфейс] [Данные]. Низ: строка статуса/валидации + кнопки
[▶ СТАРТ ПАРТИЮ] (до старта) / [ПРИМЕНИТЬ: новая партия] (в игре) + [📜 ПРАВИЛА].

**Вкладка Игроки:** набор строк игроков (до 8): колонки [№][ДРАЙВЕР▾][ИМЯ][ФИШКА▾][ЦВЕТ▾]
[СТАТУС][✕ удалить]. Кнопка «+ добавить игрока». Строка «Роль хоста: (•) играю (LOCAL) / ( ) только
наблюдаю (без LOCAL)». Драйвер: LOCAL / AI / CHAT / sdk:neuro / sdk:evil (второе sdk-место честно
помечено «играет как ИИ»). Валидация: ≥2 игрока, имена/фишки/цвета уникальны (ошибки под
полями и в статусе). Начальный порядок хода: случайный/вручную.

**Вкладка Правила:** капитал [1500], GO-бонус [200], тюрьма (оба▼) + штраф [50], бесплатная
стоянка [вкл/выкл], дубли [вкл], 3 дубля→тюрьма [вкл], аукционы [вкл], застройка [вкл],
ровная застройка [вкл], монополия×2 [вкл], залог [вкл] + 50%/110%, торги [вкл], агрессия ИИ
[слайдер 0–100].

**Вкладка Темп:** таймер хода [сек, 0=нет лимита▼], таймер аукциона [сек▼], тайм-аут
(авто-пас▼ / пометить away).

**Вкладка Интерфейс (применяется живьём, без рестарта):** анимации [вкл], звук [вкл],
журнал событий над доской [вкл], камера-«кино» [выкл], язык [RU▼/EN▼], тема плотности.

**Вкладка Данные:** RNG-сид [0 (0 = случайный)], клеток на доске [16–64 кратно 4]. Пресеты
(три кнопки сверху вкладки Данные): Классика / Быстрая (таймер 10с, капитал 1000) / Хардкор
(без залога и торгов, агрессия 80).

Тултип у КАЖДОГО поля: что делает, на что влияет, когда применится (живьём / нужен рестарт).
Поля «→ нужен рестарт» помечены тегом. В игре кнопка называется «ПРИМЕНИТЬ: новая партия» →
модальное подтверждение с диффом изменений, пересобирает движок.

## 6. ИНСПЕКТОР КЛЕТКИ (справка тайла)

Докнут в правую панель снизу, НЕ перекрывает action bar. Заголовок «КЛЕТКА» (или «TILE») +
кнопки: 📌 (закрепить, toggle) и ✕ (закрыть). Тело: «<имя>» · тип/группа · цена · аренда ·
владелец · дома/отель/заложен. Пустое состояние (ничего не выбрано): «Кликните по тайлу
доски». Авто-скрытие через 5 с, если не закреплено; hover/клик по тайлу открывает его.
С выбранного тайла доступны кнопки [СТРОИТЬ][ЗАЛОЖИТЬ][ВЫКУПИТЬ][ПРОДАТЬ дом] (по контексту).

## 7. ЖУРНАЛ СОБЫТИЙ (правая панель, «ХОД СОБЫТИЙ»/«EVENT LOG»)

Заголовок + живой счётчик + кнопка экспорта ⭳ (в .jsonl). Строка фильтров: [игрок▾]
[тип▾] [money-only ☑]. Авто-скролл к новейшей строке. Каждая строка: время, имя игрока
(цветом), описание события с НАЗВАНИЯМИ клеток (не номерами), тег-типа. Фильтр «тип»: по типу
события. «Деньги» — только денежные события. В режиме наблюдателя журнал расширяется (380px,
100+ строк). Экспорт пишет полный лог в JSONL.

**Тосты и баннеры (уведомления):** тосты сверху-центр (на 8px ниже TopBar), стек ≤3, ширина
≤46% экрана, авто-скрытие: info/success 4с, warning/danger 6с; анимация slide-down+fade 200мс /
fade-out 300мс. Анти-спам: рента/платежи одного хода сливаются в «Neuro платит $48: рента Host
×2, налог $20». Баннеры — крупные по центру над центром-сценой, 1шт, ~2.5с: покупка, старт
аукциона, «дубль!», банкротство, победа, «... идёт в тюрьму». В режиме наблюдателя тосты НЕ
отключаются (главный канал для зрителя).

## 8. РЕЖИМ НАБЛЮДАТЕЛЯ (WebGL-зритель и «хост-наблюдатель»)

Это НЕ отдельный экран, а компоновка матча, в котором нет LOCAL-места (все — AI/CHAT/SDK).
- Панель действий → тонкий статус-бар: «ход: <фаза> · <игрок> · решение за <держатель>» +
  таймер «авто-через 0:08» или «ожидание Neuro…», НИКАКИХ кнопок.
- Панель игроков → сворачиваемый рельс. Журнал — расширенный (см. §7).
- Инспектор открывается по hover на тайле. Доска — во весь центр. Тосты включены.
- Кнопка 👁 в TopBar меняется на «вернуться в настройки» (режим наблюдателя можно покинуть).
- Честная подпись: «пауза недоступна, матч живёт по таймерам».
- Вход в наблюдатель — только если хост НЕ сидит за LOCAL-местом.

## 10. ПОВЕДЕНИЕ И СОСТОЯНИЯ (обязательно отразить в макетах)

- Каждая кнопка/поле имеет тултип: формат `[действие] — [что произойдёт] — [горячая клавиша,
  если есть]`. Стиль тултипа: тёмный бокс `#0d1117`, рамка-акцент, 12px, задержка 350мс.
- Состояния кнопок: normal / hover (акцент `#5fc4ea`) / pressed (`#3a95bd`) / focus (прозрачная
  рамка) / disabled (с пояснением в тултипе, напр. «нужно минимум 2 игрока»).
- Модалки решений (торг, ответ на торг, аукцион, стройка-залог) — поверх всего, с затемнением
  фона (клик по затемнению = закрыть). Заголовки в верхнем регистре.
- Итоги партии (game over): заголовок «ПАРТИЯ ОКОНЧЕНА / MATCH OVER», имя победителя золотым
  18px, строка статистики (ходов, игроков, капитала), кнопки [РЕВАНШ][НАСТРОЙКИ].
- Ни один элемент не должен выходить за вьюпорт на всех 5 разрешениях (1440×900, 1280×720,
  1024×640, 900×600, 1920×1080) — доска целиком, панели на своих брейкпоинтах.
- Холодное состояние, состояние «ИИ ходит сам» (статус без кнопок), состояние наблюдателя —
  все продумать.

Формат вывода — markdown. Пиши на русском (подписи UI можно дублировать EN). Будь конкретным и
