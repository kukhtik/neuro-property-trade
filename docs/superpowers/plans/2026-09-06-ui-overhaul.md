# Полная переработка интерфейса — план

**Цель:** превратить playable-оболочку в полноценный, понятный, адаптивный игровой интерфейс: переработанные клетки, фишки, тултипы, правила, наблюдатель, рестарт, локализация, ассеты.

**Архитектура:** UI-слой (`game/ui/`) остаётся «кожей» поверх движка. Каждый компонент — автономный модуль с `setup(data)`; логика ввода идёт через `seat_manager.push_intent`; HUD читает `for_spectator`. Вся палитра/стили — в `ui/theme.gd` (шов для ассетов). Движок не трогаем, кроме добавления полей настроек и расширения лога.

**Технологии:** Godot 4.7.2 (gl_compatibility), GDScript, Control-дерево, Tween, AudioStreamGenerator. Тесты headless: `godot --headless --path game --script res://tests/run.gd`.

**Ветка:** `ui/overhaul`. Каждая фаза — отдельный коммит, после каждой — прогон 190 тестов + playability-проба.
