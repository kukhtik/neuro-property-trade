# Косяки прототипа glm53 (npt-glm53-uiux-0004) — НЕ переносить в Godot

Источник: vision-анализ скринов `game-board.html` (123KB, 2032 строки) + DOM-геометрия.
Прототип — ориентир по цветам (skin.json), пропорциям трёх зон и структуре окон.
При переносе в Godot эти 6 дефектов исправляются сразу (проверка: `res://tests/ui_contract_runner.gd`).

## 1. Правая сторона доски — пустые тайлы
- ~5 зелёных + 1 синяя клетка в правой колонке рендерятся голыми цветными полосками
  БЕЗ названий, цен и иконок. Выглядит как сломанный/недогруженный рендер.
- В Godot: каждая клетка периметра обязана иметь имя + цену + иконку (band orientation
  уже гарантируется board_layout_probe; здесь — полнота данных на всех N клетках).

## 2. Текст и иконки на тайлах наплывают друг на друга
- «Аэропорт-экспресс», «Южный ЖД», «Канатная дорога» (звёздочка), «Восточная …» —
  иконки поверх названий.
- «Пельменовский сад» переносится посреди слова («Пельменов / ский сад»).
- Обрезанные подписи: «Восточная …», «Ф…» (одна буква), «Северная …».
- В Godot: текст и иконка разведены через VBox/контейнер, физически не пересекаются;
  перенос по словам, авто-фит шрифта, эллипсис только как последний резерв.

## 3. Тосты перекрывают верхний ряд клеток
- Тост «Партия началась» лежит поверх верхнего ряда (район «Северная»).
- В Godot: тосты позиционируются НИЖЕ верхней границы доски / под top bar,
  не перекрывают клетки. (В текущем коде уже есть event overlay — проверить позицию.)

## 4. Вторичные действия спрятаны в обрезанные микроссылки
- «торг · стройка · залог ·» внизу слева срезаны краем экрана, почти невидимы.
- В Godot: превратить в аккуратные вторичные кнопки (secondary buttons) в action bar,
  не обрезаются, читаемы, с тултипами.

## 5. i18n неполный — модалки не перерисовываются при смене языка
- EN-локализация частичная: каркас EN, но модалка game-over («РЕВАНШ»/«НАСТРОЙКИ»,
  «Ходов: 1 · Игроков: 4 · Капитал победителя: 1500») и часть кнопок остались RU.
- В Godot: 100% перерисовка всех модалок/оверлеев при locale_changed (уже есть
  I18n.t() + locale_changed live relabel — проверить, что покрыты ВСЕ модалки).

## 6. Центр доски пуст
- Вместо «сцены · кубиков · карточки решения» — только текстовая заглушка
  «NEURO PROPERTY TRADE / СЦЕНА · КУБИКИ · КАРТОЧКА РЕШЕНИЯ». Кубиков нет.
- В Godot: центр доски — интерактивная сцена (кубики BG3 + карточка решения),
  не пустая заглушка. (dice_stage уже есть — проверить, что рендерится в центре.)

## Дополнительные косяки (зафиксированы, но не входят в 6 пунктов)
